# 🐍 Exercícios de Lógica de Programação em Python

Repositório criado para armazenar meus primeiros projetos e exercícios práticos desenvolvidos em **Python** utilizando o **Google Colab**.

## 📋 Projetos Incluídos

Neste notebook (`Exercicios_python.ipynb`), você encontrará soluções para os seguintes problemas:

1. **Verificador de Saldo para Compra (Condicionais):**
   - Recebe o valor disponível do usuário e verifica se é suficiente para comprar um produto (R$ 1.500), calculando o troco/saldo restante ou exibindo aviso de saldo insuficiente (`if/else`).
2. **Cálculo da Área do Círculo:**
   - Solicita o diâmetro, calcula o raio e retorna a área total utilizando operações matemáticas básicas.
3. **Cálculo da Área do Quadrado:**
   - Lê os valores da base e da altura informados pelo usuário e calcula a área correspondente.
4. **Teorema de Pitágoras (Cálculo da Hipotenusa):**
   - Recebe os valores dos catetos oposto e adjacente e calcula a hipotenusa utilizando potenciação e raiz quadrada em Python.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** Python 3
* **Ambiente de Desenvolvimento:** Google Colaboratory (Jupyter Notebook)

## 🚀 Como Executar

Você pode abrir e testar os códigos diretamente no navegador sem instalar nada:
1. Clique no arquivo `Exercicios_python.ipynb` acima.
2. Clique no botão azul **"Open in Colab"** no topo da visualização.
3. Execute as células clicando no botão de *Play* (`▶`) ao lado de cada código.
